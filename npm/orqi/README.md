# @orq-ai/orqi

orqi (aka TonyBot) is the orq.ai helper agent in your terminal.

```bash
npm install -g @orq-ai/orqi
orqi
```

This package is a small launcher. npm installs only the prebuilt binary for your platform
(macOS arm64, macOS x64 or linux x64) from the matching `@orq-ai/orqi-<platform>` package.

Update with `orqi update`, which runs npm for you, or `npm install -g @orq-ai/orqi@latest`. Docs and other install methods:
https://github.com/orq-ai/orqi
